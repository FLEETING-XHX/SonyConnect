### 新增功能手测步骤

1. 暂不连接耳机，分别按左 Ctrl + F1 和右 Ctrl + F1：左侧不触发；右侧显示现有设备用例的失败反馈，不能伪报操作成功。长按只触发一次，松开后再次按可触发。隐藏到托盘后重复右 Ctrl 测试，再打开窗口查看反馈。
2. 打开快捷键编辑窗口，点击字段后按住右 Ctrl，应立即显示 `R-Ctrl+…` 和“已识别”；继续按自由键才能形成完整草稿。分别复验左右 Ctrl／Alt／Shift、Caps Lock、Tab；松开识别键再按自由键应提示缺少识别键。录入左 Alt + Home、Caps Lock + End、Tab + PgUp（按住识别键再按自由键）。修改时旧绑定仍生效；录入暂停触发；Reset 只改草稿，关闭不保存。再次打开显示已保存值。重复组合或多识别键保存失败，旧绑定完整保留；Backspace 单按或搭配识别键均拒绝且原草稿保持。有效草稿保存后关闭，重启保留新设置。
3. 复验 A–Z、F1～F12、Home／End／PgUp／PgDn；尝试 Backspace、Delete、PrintScreen，确认拒绝提示。F12 使用钩子识别、不占用系统保留的 RegisterHotKey 注册路径，不能保证与调试器无冲突。记录前台应用，注意 Caps Lock 单按会切换大小写、Tab 单按会移动焦点；从其他应用切回、隐藏／恢复、Tab／Enter／Esc 焦点操作也需检查。
