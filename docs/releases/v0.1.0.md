# SonyConnect v0.1

首个 C++ 正式界面版本。产品版本号及发行标签分别为 `0.1.0`、`v0.1.0`，便于程序自动比较版本。

## 下载与运行

- Windows 10/11 x64：下载 `SonyConnect-v0.1.0-Windows-x64.zip`，完整解压后运行 `SonyConnect.exe`，无需安装 .NET。
- 下载入口：[GitHub Releases](https://github.com/FLEETING-XHX/SonyConnect/releases)、[Gitee Releases](https://gitee.com/fleetingxhx/SonyConnect/releases)。
- ZIP 的 SHA-256 见同名 `.zip.sha256` 附件；目录内 `SHA256SUMS.txt` 可校验解压后的文件。保留 config 和 notices 目录。
- 先在 Windows 蓝牙设置中配对并连接耳机，再打开程序。替换旧版前从托盘退出；本机配置和日志保留在 `%LOCALAPPDATA%\SonyConnect`。

## 本版内容

- 正式主界面、更多功能、个性化、高级设置、诊断与维护及离线时间线。
- 环境声音、EQ／CLEAR BASS、双设备音源、固定播放、本机音量与媒体控制、触摸分配与语音助手联动等已实现功能。
- 统一 85% 界面比例，调整动态高度过渡、滑条目标保持、下拉菜单与冷却交互。
- 托盘单击打开，右键提供声音模式等操作，任务栏重建后恢复图标。
- 移除旧简易 UI 和旧全局热键，分离应用适配与正式界面依赖。
- 修复媒体异步等待阻塞、外部音源变化后的编解码补读、菜单生命周期、更新分页／弹窗归属和异常退出日志保留。
- 提供匿名 GitHub／Gitee 更新检测。仅提示并打开下载页面，不自动下载或覆盖安装。

## 兼容与验证边界

当前硬件使用基线为 **WF-1000XM5**，已有开发阶段用户试用反馈及离线／正式界面检查记录。它们不等于最终 v0.1.0 包完成全部现场验收。

**WH-1000XM5、LinkBuds S、WH-CH720N 等其他型号仍待独立适配与验收，不宣称兼容。** 功能是否可写以耳机实际报告能力和已确认状态为准。

最终候选的真实快速操作／断连异常、实际媒体故障与 Explorer 重启、多屏／混合 DPI／睡眠恢复、干净 Windows 便携运行尚待集中验收。更新渠道最终在线检测与附件对应关系以发布后的实际记录为准。

手机 Quick Access 服务仍需在手机 App 内配置；电脑端不提供独立服务开关。Windows 系统原生对话框采用系统缩放。

## 归属与反馈

本项目为非官方 Windows 程序。第三方归属和许可随包保存在 notices；仓库现有许可边界保持不变。

反馈问题时请附型号／固件、Windows 版本、复现步骤，并可通过「更多 → 诊断与维护」导出脱敏诊断包。分享前仍请自行核对内容。
