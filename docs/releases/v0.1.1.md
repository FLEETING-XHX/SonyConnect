# SonyConnect v0.1.1

下载 `SonyConnect-v0.1.1-Windows-x64.zip`，解压后运行 `SonyConnect.exe`。适用于 Windows 10/11 x64，无需另装 .NET 或 Visual C++ 运行库。更新前请从托盘退出旧版，保留本机配置即可延续偏好。

## 本版更新

- 修复 WH-CH720N 初始化超时，以及控制权限被错误限定到 WF-1000XM5 的问题，按设备实际能力开放功能。
- 修复循环模式设置已生效却立即报回读不一致的问题，等待设备确认并保留真实失败提示。
- 按型号显示 NC/AMB 按钮、触摸控制和 DSEE / DSEE Extreme；不支持的功能置灰，减少操作时文字闪动。
- 头戴式耳机采用横向电量图标，调整 DSEE 标识与电量间距。
- 改为单 EXE 便携分发，内置更新源与完整第三方许可，可在「更多 → 第三方许可」离线查看和复制。

## 验证范围

WF-1000XM5 为现有使用基线；WH-CH720N 已完成连接及降噪切换的实机检查，最新循环确认修复通过离线测试，仍待实机复测。WH-1000XM5、LinkBuds S 及其他固件不宣称已完成兼容验收。功能以耳机实际能力和已确认状态为准。
