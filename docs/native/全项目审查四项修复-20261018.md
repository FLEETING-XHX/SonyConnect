# 全项目审查四项修复（2026-10-18）

## 范围与风险

按用户“修复这四项问题”的授权实施。风险等级 L3：涉及共用桌面工作线程、连接内状态补读和日志资源生命周期。不修改协议编码、请求超时策略、自动重连策略或现有控件绘制。

## 实现

1. **桌面异步等待。** 新增 `desktop_async.hpp`，将 `desktop.cpp` 的 WinRT 无界 `.get()` 改为每项最多 2 秒的等待，并每 20ms 检查退出取消。超时／取消后不再调用 GetResults，后续队列仍可执行。完成回调只持有等待信号的弱引用，晚到完成不会访问宿主、后端或已释放的事件。媒体命令、媒体属性、端点身份和蓝牙桌面查询共用此处理；保留原有设备／端点／媒体会话校验。ApplicationHost 在销毁开始时设置取消标志，取消身份读取后不继续新建耳机连接。
2. **外部音源的编解码补读。** 增加 `DeviceController::poll_codec()`，在现有后台本机读取节拍中调用。只在已连接、就绪、能力已报告、音源已确认且编解码确实需要补读时，复用现有查询；已知结果不重复查询。不改变前台 busy／last_result，保留连接、音源和 generation 屏障。查询途中音源再次变化时返回 Superseded，留待下个后台节拍读取当前音源。
3. **托盘恢复。** 新增 `tray_icon.hpp` 管理注册状态，ApplicationHost 处理 TaskbarCreated 并重新 NIM_ADD。失败时清除“已添加”状态并显示主窗口；关闭行为不会继续依据失效的托盘状态隐藏程序。退出时删除实际已注册的图标。
4. **日志运行锁。** 每次运行持有独立 `.lock` 文件句柄，覆盖整个写入线程生命周期。其他运行无法独占打开的锁表示仍活跃，必须保留；锁可打开或不存在的历史运行按保留数量清理，不再要求存在 log-end。进程异常终止后 Windows 释放句柄，因此残留日志也会进入保留策略。未知访问错误保守保留；只处理程序既有 owned_log 命名规则内的日志，导出不包含锁文件。旧版本无锁日志依赖正式程序的单实例约束，不能与旧版写入进程绕过该约束共享日志目录。
