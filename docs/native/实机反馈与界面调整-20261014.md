## 此次修改

- 通透等级移除“应用等级”，滑块松开或键盘调整结束后提交。EQ 移除启用勾选框、应用预设及各段应用按钮；在预设列表选择关闭即可关闭 EQ，选择其他预设立即提交。频段和 CLEAR BASS 增加当前数字、−10／0／+10 标注。
- EQ 手动 `A0`、自定义 1 `A1`、自定义 2 `A2` 分开处理：当前 A1／A2 编辑保留自身槽；内置预设编辑转 A0。继续核对设备发布的候选、完整曲线和回读；ACK 本身不算写入成功。
- 双设备页新增只读显示框，分列当前连接和已注册未连接的设备，标注当前音源。音源选择只列已连接项。读取失败／断开后的残留列表标注上次记录；注册记录由耳机保留，本次没有发送移除配对命令或新增自有磁盘历史缓存。
- 扩展设置改为互斥单选。触摸按键、分配、手势、自定义功能、语音指导、助手改为互斥单选；循环以四种合法组合单选，保留多模式循环含义。设备候选过多时可滚动，支持 Tab 和方向键。关机保留独立确认操作；触摸与助手保留关联确认／备份恢复。
- 修正自动关机 `0x11`＝不自动关机、助手 `0x33`＝腾讯小微／`0xFF`＝不使用、左右耳按键、单击等手势和功能 1–4 的中文标签。未知值继续显示编号，不猜测语义。
- 热键改为单个输入框：获得焦点后直接按组合键，保留左右识别键、冲突检查及保存按钮；完成或 Esc 取消后移焦至保存按钮，不吞掉后续 Tab 或重复键。
- 后台本机读取和前台写入分开记录完成状态，后台任务不会丢弃已提交的即时设置；提交失败后界面回到设备已确认的数值。

未修改 C# 源码。旧 C# 的 EQ 编辑逻辑也会统一进入手动预设；此次修正在 C++ 主工程，C# 后续独立维护时需要另行处理。

## 复测重点

1. 分别在自定义 1、2 修改一个频段及 BASS，回读和官方 App 都应保持该自定义槽。
2. 在内置预设改一个频段，应进入手动；预设选择与滑块松开均无需应用按钮。
3. 双设备显示框应同时列出电脑与手机；断开其中一台后转为已注册未连接，不删除注册记录。
4. 核对智能免摘、自动关机、语音助手和触摸功能译名；每组单选不串组，四种循环组合含义正确。
5. 热键输入、Esc、Tab、左右键区分、重复键和保存冲突检查；离开设置页后验证实际触发。
