## 工程与运行

主工程位于 `projects/cpp/CMakeLists.txt` 与 `projects/cpp/native/`；根目录 CMake／脚本保留兼容入口。目录移动及 C# 私有仓库准备见 `docs/目录与仓库分离.md`。采用 C++20、Win32 控件、WinSock RFCOMM、Windows SDK／C++/WinRT；MSVC 运行库静态链接。没有 CLR 托管入口，不启动 C# 子进程，也没有上游 checkout 或联网下载的构建依赖。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Native.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Native.ps1 -Configuration Release
```

脚本自动定位现有 Visual Studio x64 工具链，在局部开发环境中使用 Ninja Multi-Config。已有安装目录不作修改。构建脚本探测本机 MSVC 的本地化 include 前缀，确保中文编译器的头文件依赖被 Ninja 记录；没有硬编码英文输出。IDE 使用开发者环境打开文件夹；CMake presets 提供 Debug／Release 构建和测试入口。输出为 `build/native-ninja/<Configuration>/SonyConnect.exe`。

便携包使用 `scripts/Publish-Native.ps1`，输出到带时间戳的 `artifacts/native/packages/`。脚本执行 Release 构建与回归、安装 EXE／配置／许可、检查 x64 PE 的 CLR 目录为零，并在安装后的 EXE 上运行离线界面测试。

`--offline` 打开不调用蓝牙／更新网络的界面。`--ui-self-test --report <path>` 执行构造状态的界面回归并输出 JSON 和七页 PNG。`--start-hidden` 在托盘成功创建后隐藏启动；托盘创建失败时仍显示主窗口。

原 `SonyConnect.sln`、`src/`、`tests/` 与阶段脚本已移至 `projects/csharp/` 并继续保留，用于 C# 基线回归、既有实机证据对照和回退。原程序与原配置未删除。测试原生程序前从托盘退出原 C# 程序，控制通道继续与手机 Sony App 交替使用。

## 握手与参考依据

以现有 C# 的 `TandemCodec`、`MdrHandshake`、各 `Mdr*Parameters` 和协调行为为迁移基线，同时核对：

- `references/SonyHeadphonesClient`：`193c1e053836119eb875c97331dd10c1aef206bc`，MIT，MDR V2／Tandem 定义与既有固定捕获样本。
- `references/sony-device-center`：`0bf98223c1ba402dd6c5136c21e6ab35482e4390`，MIT，C++20 传输／协议／设备／界面分层参考。没有直接引入 Qt 或 ImGui 客户端。
- 既有官方 APK 静态分析：`artifacts/rea-sony-static-20261013/derived-frames.json`、evidence index 及 `docs/开发与协议记录.md` 的握手记录。静态派生字节与既有握手定义一致，不作为实机抓包或发送序号脚本。

顺序为 `00 00` 协议信息 → `02 00` capability information → `04 01` 型号 → `04 02` 固件 → `06 00` Table 1 功能 → 设备开启 Table 2 时再读取其功能。V2 版本为 32 位大端、table flag 的 `00` 表示启用；识别 V1 后明确报告不支持当前 bootstrap，不编造 V1 控制路径。

接收匹配同时检查当前物理连接、table、response command 与 discriminator。ACK 表示送达；有可读取状态的写入必须经参数响应／通知确认。写入不自动重发；只读重试由有限策略控制。未知值、不可用能力、过期连接和型号限制继续保守处理。自动恢复只握手和读取，不重放写入。

MIT 原始许可保存在 `native/notices/`，随便携包分发。APK 代码与素材、Gadgetbridge AGPL 代码／测试／fixture／二进制未纳入产品。

Windows 传输与 DPI 处理另对照微软的 [SOCKADDR_BTH](https://learn.microsoft.com/en-us/windows/win32/api/ws2bth/ns-ws2bth-sockaddr_bth) 与 [WM_DPICHANGED](https://learn.microsoft.com/en-us/windows/win32/hidpi/wm-dpichanged) 文档；实现结果仍以本项目的编译与运行证据为准。

## 功能映射

| 模块 | 原生实现 | 关键约束 |
| --- | --- | --- |
| 协议 | `protocol.hpp`／`protocol.cpp` | 帧长度／转义／校验、流式恢复、握手、能力、全部既有参数类型 |
| 蓝牙与会话 | `session.hpp`／`session.cpp` | 已配对发现、V2 UUID、连接期限、序号 ACK、请求匹配、通知去重与过期栅栏 |
| 设备控制 | `DeviceController` | 电量、声音／通透／语音关注、EQ／BASS、双设备／音源／固定播放、扩展设置、触摸／循环／向导／音量 |
| 写入边界 | 同一控制入口 | 沿用 WF-1000XM5 写入限制；其他型号不由通用能力列表直接开放写入 |
| 关联恢复 | 触摸与语音助手备份 | 显式关联确认、当前连接内备份、独立恢复按钮、完整参数保留与回读 |
| 本机播放 | `desktop.hpp`／`desktop.cpp` | Bluetooth AEP／容器关联、目标端点与媒体会话校验；不改默认输出，不遥控手机媒体 |
| 桌面生命周期 | `main.cpp` | 托盘、单实例、开机启动、关闭到托盘、后台工作线程、睡眠与蓝牙状态恢复 |
| 热键 | `GlobalHotkeys`／`HotkeyCapture` | 左右识别键、自由键、真实录入、注入／重复处理、冲突校验、仅按键状态 |
| 更新 | `SoftwareUpdateService` | 使用既有 `config/update-source.json`，GitHub／Gitee 手动检测、HTTPS 校验、不自动安装 |
| 诊断 | `DiagnosticLog` | 四段日志、大小／保留数量限制、脱敏 ZIP、旧 `.scdiag` 兼容导入、只读全量时间线 |

界面为七页功能验证控件，不作为正式 UI 准入或完整视觉设计成果。声音／均衡器等参数保留未知、已过期与不可写状态；无可用读数的音压不显示推测值。控制台历史探针脚本仍由保留的 C# 基线执行，不伪称已移植成 C++ CLI。

## 设置与文件保留

原生运行设置位于 `%LOCALAPPDATA%\SonyConnect\Native\`，不覆盖原 C# 设置。热键与桌面／日志设置在覆盖前保存备份；未知版本热键配置拒绝覆盖。开机启动单独使用当前用户 Run 的 `SonyConnect.Native` 值。原有程序产物、研究 APK、参考 checkout 与原始实测日志保持原位置。

导入旧诊断包不改写旧日志，也不连接设备。导出拒绝覆盖日志源文件，校验 archive 名称、ZIP／DEFLATE／CRC／大小边界。保存 `.scdiag` 文件时仍使用系统覆盖确认。
