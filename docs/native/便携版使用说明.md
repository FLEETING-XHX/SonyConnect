# SonyConnect 原生便携版

解压整个目录，运行 SonyConnect.exe。v0.1（版本号 0.1.0）为 Windows x64 原生便携版，无需安装 .NET；请保留 config 和 notices 目录。发布包不表示所有型号、固件和异常场景均完成实机验收。

## 使用

1. 先在 Windows 蓝牙设置中配对并连接 Sony 耳机，再运行本程序；未找到耳机时可点击主界面右侧刷新图标。
2. 托盘单击打开主界面，右键提供更多功能、个性化、声音模式与退出。不支持的设备功能置灰。
3. 「更多 → 诊断与维护」可配置日志限制、导出脱敏诊断包、只读查看历史事件以及选择 GitHub/Gitee 检查更新。
4. 旧全局热键功能已移除。手机 Quick Access 等依赖手机软件的功能不在电脑端提供独立开关。

## 数据、网络与兼容范围

- 用户配置、日志保存在当前用户的 `%LOCALAPPDATA%\SonyConnect`。日志有容量和保留次数限制；诊断包是脱敏事件时间线，不包含原始协议负载，不向耳机重放指令。
- 更新源配置为 `config/update-source.json`。更新采用匿名 HTTPS 查询公开 GitHub/Gitee Releases；网络失败与没有发布会分别提示。不静默安装或覆盖当前 EXE，不内置 PAT/访问密钥。
- 正常运行会按现有 Windows 蓝牙/耳机控制流程发现和连接设备。导出的诊断包可含型号、固件与操作时间，请在分享前核对内容。
- 当前 WF-1000XM5 基线有用户试用反馈；自动离线检查不等于逐项实机验证。WH-1000XM5、LinkBuds S、WH-CH720N 是后续独立适配任务，不能据此包推断已经兼容。
- 当前版本的现场异常、混合 DPI/多屏、睡眠恢复、干净 Windows 和真实连接资源验收集中在 SC-27。线上新版本/附件校验闭环由 SC-21 单独记录。

## 更新、移动与恢复

从托盘退出后，再替换完整便携目录；保留用户配置可延续偏好。移动 EXE 所在目录后，如启用了开机启动，请重新关闭再打开该设置以刷新路径。不要让两个不同版本同时控制同一副耳机。

需要恢复设置时，先退出程序，备份 `%LOCALAPPDATA%\SonyConnect` 再重命名该目录；重新运行后使用默认配置。不要在程序运行时覆盖配置。需要恢复旧版时退出当前版本后运行保留的旧目录。

## 卸载与校验

先关闭开机启动，再从托盘退出，删除解压目录即可。用户配置与日志可自行备份后删除。`SHA256SUMS.txt` 列出随包文件的 SHA-256；发布候选摘要另列 ZIP 与 EXE 的校验值。
