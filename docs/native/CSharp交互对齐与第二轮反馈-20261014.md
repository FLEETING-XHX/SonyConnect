- 发现仅返回 Windows 蓝牙当前连接且已配对的 Sony 耳机。查询使用 `fReturnConnected`，并逐个检查 `fConnected`、`fAuthenticated`；不执行新设备搜索或主动连接历史耳机。
- 语音指导置灰的根因是 C++ 曾硬性限制类型 3，且漏处理类型 0／1／2 的开关能力。现在按 C# 读取能力和可用状态；需要语言的类型保留当前已确认语言。缺少开关能力、语言未确认或状态不可用时仍禁写，不跳过协议保护。
- 循环恢复为降噪／通透／关闭三个复选框。用户已更正为至少选择两个：两项或三项勾选后立即提交，少于两项恢复最后确认组合。全三项＝1，降噪＋通透＝2，降噪＋关闭＝3，通透＋关闭＝4。
- WF 的单击动作、功能 1–4 与循环模式是同一底层参数，不再重复显示“自定义手势／手势功能”。这些名称是 C++ 验证界面的标签，不是已证明的官方 App 译名，也未确认是 WH 专属。设备若报告独立的非循环动作，保留高级编辑与底层实现。
- 扩展选项、触摸分配、语音指导、助手、音源选择直接提交；提示音量松开提交；移除二次应用按钮。触摸分配只有后端确认存在右耳／语音助手联动时才弹确认，并在同一设备会话内刷新、备份、写入与回读。
- 通透与本机音量拖动按 120／80 ms 合并输入，并在松开后保留最后值；EQ 仍在松开、按键释放或失去焦点后提交。后台读取、连续输入、会话变化和失败回读保持串行保护。
- 热键草稿保存、日志配置保存、耳机关机确认、固定播放长按继续保留其原有含义。

上一轮 EQ 修正保留：自定义 1／2 编辑保持各自槽位，内置预设进入手动；没有将 C# 的旧槽位错误恢复到 C++。
