# SC-23～25 收尾与验收

日期：2026-10-18。承接《在线更新与 SC23-25 验收盘点》。本记录区分代码实现、离线/桌面测试和真实设备验收，不依据 Linear 的旧 Backlog 标签判断功能是否已实现。

## 本轮实现

### SC-23：窗口、工作区和 DPI

- 提取并复用工作区定位计算，支持负坐标及不同任务栏占用边界，子窗口优先在主窗口左侧打开，空间不足时移到右侧并限制在工作区。
- 设置页处理 DPI 变化时采用系统建议的位置，再重新计算可用空间；显示变化时取消旧菜单和编辑。
- 补齐 125% 的四个正式窗口检查；用纯布局输入覆盖 125%、150%、175%、200% 及负坐标工作区。
- 当工作区宽度不足以容纳 680 DIP 的设置页时，按可用宽度缩放整页，保留所有控件和纵向滚动。正常宽度保持系统 DPI，不进行额外放大。受限宽度下字号会随整页缩小，这是保留双列布局的取舍。
- 保留既有主窗口、更多设置、个性化和高级设置；热键窗口按用户决定取消，未恢复旧任务中的过时入口。

### SC-24：菜单、完整名称和偏好

- 菜单按可用空间向下或向上打开；不足六行时减少可见行数并保留滚动条，防止遮住原选择框和越界。
- 支持方向键、Home/End、PageUp/PageDown、Tab 和 Esc；Esc 先关闭菜单并恢复原控件焦点。
- 正式窗口控件提供原生悬停提示；F1 可打开完整内容。媒体信息增加可聚焦的查看区域，点击或 Enter 可查看完整歌名和音源。
- 无关状态更新保持菜单身份；设备候选、触摸耳侧或能力发生实际变化时立即取消旧菜单，残留通知不能操作新上下文。确认值变化时只更新菜单的选中标记。
- 四个滑条外观分别从磁盘恢复；补充非法值回退、其他配置保留与备份检查。

### SC-25：取消与生命周期

- 隐藏、失焦、睡眠消息及显示变化会取消相应拖动/菜单/待提交滚轮编辑；隐藏后刷新状态不会重启动画计时器。
- 主界面与设置页在取消编辑时，只移除该控件尚未提交的值，保留其他控件的排队值和已经开始的操作。后者仍由现有控制器的实际结果决定。
- 隐藏窗口会停止动画、长按、滚轮和冷却计时器；重开时按原截止时间恢复冷却，不能通过重开绕过 200ms / 150ms 限制，也不会一直禁用控件。
- 连接变化清除旧的模式预选、双设备开关预选和长按点击抑制，避免新设备继承上一连接的临时 UI 状态。
- 重复创建/销毁页面检查包含原生输入、提示窗口、GDI/USER 资源。动画保持展示用途，没有增加逐帧设备写入。

## 验证边界

执行 Debug / Release 增量构建及本次受影响的定向检查。具体运行结果和各项证据见 `artifacts/ui-sc23-25/verification.json`；未执行简易 UI 全量测试、蓝牙协议全套回归或所有耳机型号测试。

本机实际枚举到一个 2560×1440 显示器。负坐标、其他任务栏位置和多屏布局属于离线布局输入；睡眠恢复属于向正式窗口发送系统消息的测试，没有实际让用户电脑睡眠。不能据此声称真实混合 DPI 多屏迁移、显示器拔插、休眠重连已经验证。

测试中曾出现屏幕被 Chrome 遮挡，随后增加遮挡识别、补齐测试 DPI 上下文。用户确认解锁并暂停操作后，实际设置页像素检查通过。主窗口长按曾有一次失败；增加消息跟踪后完整 32 项通过，未确认首次失败根因，未把这次失败直接归因于协议或耳机。

真实设备试用建议按以下顺序记录结果：

1. 切换六种声音模式方向，观察展开/收起、失败时回退及冷却；拖动或滚动音量后立即隐藏再重开，确认不会延迟补发旧操作。
2. 切换两个音源，长按固定、解除固定；操作中隐藏、取消或变更连接，确认实际结果与显示一致。
3. 打开 EQ/触摸/助手菜单时观察背景更新；尝试长名称、键盘选择及取消；重启程序核对四种外观偏好。
4. 有第二个显示器时，再完成真实跨屏、不同缩放和显示器变化验收。
