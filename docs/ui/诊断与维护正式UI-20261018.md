# 诊断与维护正式 UI

日期：2026-10-18。风险等级：L3（复用窗口输入组件、文件任务与窗口生命周期）；未修改蓝牙协议、会话层或设备控制指令。

## 实现范围

- 依据 Pen 42「诊断与维护」（680 × 592 DIP）、44「诊断回放」（680 × 527 DIP），沿用现有正式窗口、配色、菜单、DPI 与工作区适配。
- 「更多 → 诊断与维护」打开正式页面，包含日志容量、保留运行数、应用限制、诊断导出、离线回放、GitHub/Gitee 渠道、异步检查/取消、Releases 入口与版本信息。
- 复用现有 DiagnosticLog 和 UpdateService。渠道选择是本机设置，无需连接耳机；保存配置前保留备份，不覆盖其他配置项。
- 数字输入范围为 1～8 MiB、1～100 次；错误在当前页面提示。设备刷新保留输入草稿、选区和焦点。
- 回放在正式窗口内显示只读时间线，替代原先打开记事本的入口。事件保持原始顺序，提供来源、完整时间与错误等细节；未知事件保留原名称。F1、回车或双击可查看所选事件完整信息。
- 时间线按可见行绘制，支持滚轮、键盘导航与滚动条；不为每条事件创建控件。隐藏窗口时取消拖动捕获。
- 文件导入/导出复用现有串行工作队列，避免在界面线程执行实际文件处理。取消或导入失败保留原文件与时间线；页面关闭后完成读取不会重新弹出窗口。
- 文件错误只显示在诊断页面，不会变成主页的「耳机回读错误」。错误颜色为 B56C25 / FFF2E4。日志服务状态与操作成功反馈分别显示。
- 原开发验证界面保留；正常诊断入口和本轮隐藏对接检查均不显示该界面。回放不连接蓝牙，也不重放设备指令。
