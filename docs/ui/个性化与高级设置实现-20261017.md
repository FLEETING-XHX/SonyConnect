# 个性化与高级设置

## 已实施（L2）

- 复用 MoreWindow 的输入、下拉菜单和整帧绘制，按 SettingsPage 创建独立的个性化（416 DIP）与高级（680 DIP）窗口。
- 个性化四项：音量、环境声音、EQ、BASS，各自选择 Wake / Elastic，缩略图预览，即时生效。音量 Wake 保持 32 根，通透环境声 Wake 保持 20 根。
- 本地 desktop.ini 分别保存四项样式。旧 SliderStyle 作为缺省值兼容；写入前保存 .bak，保留其他配置节。
- 高级页：安全聆听、实际助手候选、会话内关联备份恢复确认。
- WF-1000XM5 的触摸手势按左右耳当前分配只读展示；快速注意不单独开关；音乐播放期间四次或更多次轻按，左减右增；未分配侧禁用该手势。
- Quick Access 在手机端配置，不添加 Windows 独立开关。其他型号保留实际上报的可编辑触摸手势入口，不把 WF-1000XM5 的规则推广给其他型号。
- 控件属性仅在实际变化时更新；打开的下拉不随电量刷新重建；更换连接会取消旧会话菜单；未知和忙碌状态阻止设备写入。
- 小工作区通过滚动保留标题栏与末项可达；Tab / Esc 复用既有交互。

## 已批准实施的联动（L3）

用户已批准 artifacts/ui-settings-pages/assistant-link-plan.md 及针对性验证。联动由 main.cpp 的既有串行工作队列调度，settings_flow 负责规划、前置值核对、逐步回读和备份合并；session.cpp 与协议编码保持原有实现。

- 没有播放控制时启用移动设备语音助手：显示设备上报可分配播放控制的左/右耳，确认后先分配再开启助手。
- 移除最后一个播放控制且移动设备语音助手开启：先展示实际耳侧和助手联动内容，确认后先关闭助手再更改分配。取消不提交。
- 每一步复用现有控制接口；只有回读确认才执行下一步。连接、设备身份、按键顺序、已知分配或助手状态变化会停止后续提交。
- 第二步失败不会假装整组回滚。已确认的部分状态作为本次连接内备份的当前值，允许用户再次确认恢复。
- 恢复前核对备份仍对应当前值；手机修改或重新连接会使旧备份失效。成功恢复清除应用层备份。
- 独立关闭助手仍使用已有助手接口，不要求先修改耳侧分配。

原有会话层关联备份仍可恢复，不扩展其原本受支持的协议告警范围。设备端没有跨设置原子事务；手机与 Windows 同时操作仍有时间窗口，异常以实际回读结果为准。两耳都为播放控制时仅移除一侧的规划规则是推导，仍需实机验收。
