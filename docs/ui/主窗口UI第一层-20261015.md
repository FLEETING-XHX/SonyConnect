## 本轮交付

将最新 Pen 的主窗口布局接入当前 C++20 / Win32 程序，使用 Windows SDK 的 Direct2D / DirectWrite 绘制，不新增外部 UI 框架。界面层通过回调使用原有 `DeviceController`、工作线程、本机播放服务及滑块提交机制；没有修改协议、会话或桌面服务实现。

主窗口当前实现默认 Wake 外观，包含：

- 融入界面的标题栏、设备选择、最小化、关闭；标题栏无 Logo。
- 不提供最大化或全屏；移除窗口拉伸样式及系统菜单缩放项，阻止双击标题栏最大化。
- 主窗口保留拖动位置，按 DPI 与内容状态自动选择布局高度；工作区高度不足时滚动内容，标题栏保持固定。
- 当前连接、电量、声音模式、通透等级与关注语音、双设备与音源、连接质量与实际编码、本机媒体与音量、音压、版本及更多入口。
- 当前音源按住一秒固定、提前松开/移出/失焦/Esc/会话变化取消，右键解除固定。
- 未连接、连接中、控制失败、单电量和固定播放的展示路径；未知读数显示占位，不用预览值填充真实状态。
- 原生 BUTTON / TRACKBAR 控件保留键盘焦点和可访问名称，选中状态加入名称；高 DPI 下控件绘制与点击区域都裁切在标题栏下方。
- 程序、任务栏及托盘接入用户选定的多尺寸 ICO；未连接页保留最新原型中的银白耳机素材用法。
- 启动后使用既有发现接口读取 Windows 已连接的 Sony 候选，单副耳机时连接，多副时由标题栏选择。菜单按设备地址绑定，避免列表排序变化导致连接另一副耳机。

## 运行与预览

正常运行：`build/native-ninja/Release/SonyConnect.exe`。更多按钮暂时打开现有七页功能窗口，保留完整功能入口；关闭该窗口返回主窗口。

隔离的离线视觉预览：

```powershell
& build/native-ninja/Release/SonyConnect.exe --preview-main connected
& build/native-ninja/Release/SonyConnect.exe --preview-main ambient --preview-dpi 192
& build/native-ninja/Release/SonyConnect.exe --preview-main disconnected --capture-main artifacts/ui-main-window/disconnected-96.png
```

`--preview-main` 支持 `connected`、`ambient`、`disconnected`、`connecting`、`failed`、`single`、`fixed`。预览强制离线，不构造设备控制器、全局热键、诊断服务或网络服务，构造读数标明“离线设计预览 · 示例数据”；设备及系统操作禁用。窗口自身的最小化、关闭、滚动以及更多功能窗口的离线查看仍可使用。

`--preview-dpi` 仅允许与预览模式组合，支持 96–384；`--capture-main` 保存预览 PNG 后退出。`--offline` 继续支持，不启动真实服务；`--ui-self-test` 保留既有功能回归入口。

## 下一层与限制

- 主窗口目前使用 Wake 默认外观；Elastic 外观及样式持久化随个性化层继续接入。
- 更多功能及其他子窗口暂时保留原界面，下一层按 Pen 逐步替换。原型复审中列出的恢复确认、触摸分配、样式选中值和更新来源等标注问题，在相应子窗口实现时须按真实接口校准。
- 托盘菜单仍使用现有原生菜单；图标已接入，菜单视觉后续统一。
- 新主窗口真实耳机写入、长按固定与媒体控制的端到端实测，以及真实跨屏 DPI、托盘恢复/睡眠等行为仍需验证。现有服务的历史实测通过不等于新 UI 已实机验收。
- SC-21 线上更新验证仍安排在正式 UI 各层完成后。

Direct2D DC 绘制与窗口系统命令约束分别参照微软的 [BindDC](https://learn.microsoft.com/en-us/windows/win32/api/d2d1/nf-d2d1-id2d1dcrendertarget-binddc) 与 [窗口系统命令](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)；实际完成范围以上述编译与离线证据为准。
