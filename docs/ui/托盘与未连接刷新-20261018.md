# 托盘菜单与未连接页面刷新

日期：2026-10-18。风险等级：L2，界面事件、菜单展示与既有操作路由。

## 修改

- `projects/cpp/native/src/main.cpp`：托盘由双击改为单击释放打开，兼容键盘选择事件；右键菜单中的更多功能、个性化设置指向正式页面，退出保留原生命周期。旧「本机设置」简易页面不再作为托盘入口。
- `projects/cpp/native/include/sonyconnect/main_window.hpp`、`projects/cpp/native/src/main_window.cpp`：新增托盘菜单展示接口，沿用 Pen 图标、字体与绘制器；菜单以 Pen 37 为依据，包含连接状态、打开主界面、更多功能、个性化设置、降噪/通透/关闭、退出和版本信息，删除托盘「查看蓝牙」。原生菜单追踪处理键盘、取消和外部点击，外框由 Windows 绘制。
- 菜单勾选当前模式；未连接、设备不支持、忙碌或冷却时声音模式置灰。选择时再次通过主界面既有 `select_mode` 校验，复用 200ms 冷却、待回读锁定与原有设备操作。
- 未连接页面右侧新增 32×32 DIP 刷新入口，图标使用现有 `rotate_cw`；只调用既有搜索接口，不打开蓝牙设置。搜索/连接忙碌时禁用，缩短说明文本区域以免重叠。页面原「查看蓝牙」按钮保留。
- `projects/cpp/native/tests/main_window_tests.cpp`：补充刷新路由、防重复请求、托盘内容、置灰、勾选、键盘选择及共用声音模式分发检查，记录菜单图像。
