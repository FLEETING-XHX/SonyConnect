# 状态更新与无闪烁验收要求

记录日期：2026-10-15。用户要求贯穿后续全部 UI 开发；当前阶段仍为主窗口开发。

## 适用范围

主窗口、更多设置、高级设置、热键设置、个性化及后续其他子窗口。实现每一层时都检查状态更新造成的闪烁，不等所有页面完成后集中修补。

## 实现要求

- 区分设备真实状态、用户输入目标与临时操作锁。等待回读可以禁止冲突输入，但不能让无关控件、设备名称和状态文字反复变灰、消失或重新出现。
- 比较呈现值后再更新文字、选中值和可用状态；相同状态重复到达时不重新设置控件，不重新创建页面。不要仅因快照版本变化而重置整个界面。
- 绘制与布局保持同步，避免先擦除后补画、移动时复制旧像素、背景色短暂露出或多个控件分别呈现半帧状态。必要时整帧提交，但避免无差别高频重绘。
- 同尺寸的模型更新也必须提交真实可见帧；不能只验证辅助功能值或离屏截图。专用帧请求合并调度，动画在布局和同步回调后检查活动状态，避免中途启动的动画被提前停掉。主窗口采用完整位置/尺寸/画布提交，相关回归见[重绘提交与固定状态补读](重绘提交与固定状态补读-20261016-r7.md)。
- 设备回读、音压、电量和媒体轮询不得抢走焦点、改变滚动位置、关闭下拉菜单、重置拖动或覆盖尚未提交的输入。
- 可选功能使用模块测量后的高度及稳定键；动画、后续布局、裁切和输入命中共用同一份结果，不以耳机型号或固定额外高度代替实际内容。相同目标的回读不得重启动画。
- 热键录入期间，后台状态更新不得打断录入、清空当前组合或反复刷新冲突提示；设备状态变化不得重建热键设置页。
- 普通回读成功不显示反复变化的确认标签。设置回读失败才显示对应的 Pen 错误提示（文字/图标`#B56C25`，背景`#FFF2E4`），清除临时目标并恢复设备已确认状态；未知或断开必须如实显示。
- 真实断开、能力变化、失败与页面依赖关系仍需及时呈现，不能通过冻结旧数据或绕过输入检查来隐藏闪烁。
- 复用现有通信与串行操作接口；可见性决定相关读数的轮询需求，不得因某个旧页面隐藏而阻止新页面取得数据。遵守设备最小更新间隔，隐藏/最小化后停止不必要的可视读数轮询。

## 每一层的验收

- 连续相同快照，以及仅电量、音压、媒体等无关字段变化：静态区域像素、布局与控件身份保持稳定。
- 请求开始、等待回读、成功、失败回滚：无关区域不闪色，输入锁仍有效，错误提示只在需要时出现。
- 下拉展开、数值拖动、文本编辑、热键录入、滚动期间更新：保留用户当前交互状态。
- 页面显示/隐藏、最小化/恢复、连接变化、高 DPI 与内容高度过渡：检查闪白、重影、裁切及焦点异常。
- 采用现有自动回归和实际视觉检查共同验收；静态截图与离线像素检查不能替代设备操作时的动态观感。
- 同一桌面上依赖焦点、指针和真实 HWND 的 UI 测试顺序执行，避免多个测试窗口互相干扰。

本文件是后续开发要求，不表示尚未实现的设置页已通过验收。主窗口当前修复与已知复测项见[主窗口视觉与音压修复](主窗口视觉与音压修复-20261015-r3.md)。

后续控件的失焦、鼠标捕获转移和松开处理须区分交互所有者：旧控件通知不能释放新控件的捕获，默认按钮处理松开前不能提前清理其捕获。除命令级测试外，增加焦点/捕获交接、原生按钮过程和消息循环路径回归。当前修复见[鼠标捕获与音源交互修复](鼠标捕获与音源交互修复-20261016-r6.md)。

后续布局与呈现机制见[动态布局与窗口过渡](动态布局与窗口过渡-20261015-r4.md)。

透明画布/图层使用灰度文字抗锯齿；原生输入控件的绘制通知不能反向触发整窗重复绘制。重复操作验收同时检查消息队列、空闲重绘、文字颜色、GDI/USER对象及真实屏幕命中，不能只比较离屏截图。主窗口声音模式最终采用200ms最小间隔，并继续等待未结束的设备操作。相关修复与回归见[主窗口稳定性与Wake样式](主窗口稳定性与Wake样式-20261015-r5.md)。
