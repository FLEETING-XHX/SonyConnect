# WF-1000XM5：触摸分配与移动设备语音助手修订

日期：2026-10-17。用途：修正后续高级设置设计和实现依据。

## 范围与证据

- 用户当前 WF-1000XM5 的 Sony App 操作反馈及两张确认对话框截图。
- 用户已更正：音量手势为**四次或更多次**，不是三击。
- Sony 官方指南：[关于触摸传感器](https://helpguide.sony.net/mdr/2963/v1/zh-cn/contents/TP1000782977.html)、[音乐播放与音量调节](https://helpguide.sony.net/mdr/2963/v1/zh-cn/contents/TP1000782038.html)。
- 本轮检查当前 Pen 文档和现有代码，没有进行新的耳机实机测试。
- 以下联动规则先限定于当前型号的“移动设备语音助手”；不直接推广到其他耳机型号或其他助手类型。

## 1. 快速注意是触摸分配中的固定行为

依据用户反馈：某侧分配为“环境声音控制 / Quick Access”时，该侧长按启用快速注意；不能单独关闭快速注意。

- 删除 WF-1000XM5 高级设置中的“选择手势 → 修改为快速注意”编辑入口。
- 保留左右耳整体触摸分配，手势说明作为随分配变化的只读内容。
- 不要删除整个高级设置页；安全聆听和移动设备语音助手等入口仍然有效。
- **快速注意（官方中文指南称快速提醒模式）与 Quick Access 是不同功能**，不能共用含义或开关。
- Quick Access 的服务选择和所需手机应用检查由手机 App 处理；Windows 页面不提供独立开关或服务配置，保留设备实际的触摸分配名称并注明在手机端配置。

## 2. 移动设备语音助手独立开关，但长按依赖播放控制

依据用户反馈及截图：移动设备语音助手允许单独关闭；其长按操作嵌入分配为“播放控制”的耳机单元。

### 移除播放控制时

用户演示：左耳为环境声音控制、右耳为播放控制，且助手开启；将右耳改为未分配或环境声音控制时，App 提示该修改会禁用助手，要求确认。

设计应在提交之前展示实际联动内容，例如：

> 更改触摸分配？更改后没有耳机分配为播放控制，移动设备语音助手将同时关闭。

- 列出实际受影响的左耳或右耳，以及助手开启到关闭的变化。
- 取消：不提交分配或助手修改。
- 确定：复用已经验证的控制接口；回读分配与助手状态后显示实际结果。
- 保留仍有作用的关联备份和恢复能力；恢复前也要检查依赖，不默认恢复成功。
- 一般化判断应使用“更改后是否还存在播放控制”，不能硬编码成“右耳 → 未分配”。**两耳都为播放控制后只改掉一侧的行为仍需补充实测。**

### 没有播放控制时启用助手

用户第二张截图已有该流程，当前 Pen 未覆盖：

1. 提示必须先将一侧触摸功能改为播放控制。
2. 选择“更改左侧的功能”或“更改右侧的功能”，只列出设备实际允许修改的侧。
3. 展示所选耳机原分配到播放控制的变化，以及助手的目标状态。
4. 取消则全部保持原样；确认后执行已有接口并回读两项状态。
5. 未知状态、无合法候选或部分执行失败时，以实际回读为准，不伪装为全部成功或已回滚。

## 3. 音量手势只作固定操作说明

| 对应耳机单元 | 触摸分配 | 音乐播放期间的音量手势 |
| --- | --- | --- |
| 左耳 | 已分配有效功能 | 快速轻按四次或更多次，降低音量 |
| 右耳 | 已分配有效功能 | 快速轻按四次或更多次，提高音量 |
| 任一侧 | 未分配 | 据用户反馈，该侧的四击音量操作禁用 |

- 左减右增是按物理耳侧固定的方向，不随环境声音控制或播放控制分配互换。
- 不新增独立“音量手势分配”或左右音量方向开关。
- 官方指南说明：没有音乐播放时，不能使用此手势调节音量。
- “未分配时四击禁用”及其余分配下保留四击的具体行为，来源为本轮用户观察；本轮未重新做设备验收。
- 三击仍可能用于播放控制的上一曲或 Quick Access，不能把它写成音量操作。

## 5. 现有代码覆盖与边界

- `session.cpp::set_touch` 已有部分关联确认/备份，但前置判断限定 `key == 1 && preset == 0xff`，不能视为覆盖上述所有情况。
- 设备返回关联告警时，现有流程也包含右耳限定；扩展到左耳前须核对实机告警，不能直接删除条件。
- `session.cpp::set_voice_assistant` 目前验证上报候选并写入/回读；没有完整的“选择左耳或右耳改为播放控制”的用户流程。
- `main.cpp` 现有确认文字仍固定指向右耳关闭分配，之后需要随实际依赖更新。
- 高级触摸底层接口仍保留；本轮没有删除接口、修改协议或写入设备。当前型号缺少独立开关，不等于其他型号或设备上报的所有动作接口都无效。

涉及会话依赖和设备联动的后续修改按 L3 处理，先提供实施方案并确认，再做针对性测试与实机验收。
