## 正式界面的依赖

```text
SonyConnect（启动参数、单实例、公寓初始化）
  → sonyconnect_app（后台消息、任务队列、状态投影、操作适配）
    → sonyconnect_ui（正式窗口、绘制、交互与设置联动计划）
      → sonyconnect_session → sonyconnect_protocol
      → sonyconnect_desktop（播放、更新、诊断等桌面服务）
```

- `main.cpp` 只保留启动入口；应用适配移入 `app_host.cpp`，通过 `app_host.hpp` 的 AppOptions 启动。
- 后台保留零尺寸、无页面、无子控件的顶层消息窗口，用于托盘、单实例唤醒、系统设备／睡眠通知、定时轮询和异步结果。它不是可打开的简易窗口，也没有显示入口。
- 正式界面直接传递声音模式、开关值、滑条目标、触摸分配等参数。EQ／提示音量草稿和高级触摸当前选择由应用状态持有，不通过隐藏的 Trackbar／Checkbox／Radio／Combo 读写。
- 保留现有控制器调用、串行队列、连接代次检查、滑条等待／确认／失败回退、固定状态补读和安全聆听偏好。不修改 protocol.cpp、session.cpp 或协议编码。
- 正式窗口检查程序复用 sonyconnect_ui 库，不再各自重复编译同一套 UI 源文件。资源探针因有独立插桩，继续保留自己的 UI 编译目标。

## 移除项与保留项

- 删除七页简易窗口的控件创建、布局、单选／下拉同步、原生控件事件适配、旧窗口截图及测试实现。
- 删除 GlobalHotkeys、HotkeyCapture、HotkeyMatcher、HotkeyStore、Recognizer、全局键盘钩子、配置保存与对应旧热键专用检查。不是将这些实现仅置为 disabled。
- 删除 MoreAction::hotkeys 及暂停开关。正式窗口其余入口的 HWND 控件编号保持稳定；继续检查失效的旧入口编号不触发操作。
- 保留正式界面正常的 Tab／方向键／Enter／Escape 导航；不把普通键盘可访问性当成全局热键删除。
- 保留现有用户配置、hotkeys.json 与备份、协议研究、APK、设计稿、第三方资源／许可原文、历史发布包及实测证据。旧 hotkeys.json 目前不读取、不覆盖，也不删除。
