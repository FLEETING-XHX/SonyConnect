## 关联可靠性修复

- 先转移焦点，再建立 slider drag / source hold，防止旧控件失焦把新交互取消。
- 取消交互时释放本窗口自有鼠标捕获。音量的连续变更已提交则不会因 Escape 撤销；Escape 停止当前交互，不承诺撤销已发请求。
- 保留最新 pending/in-flight 音量、环境声音目标，避免旧回读覆盖拖动值；完成或失败后恢复实际读数。
- 在 worker 执行前再次核对 slider 会话 link，音量另核对 AEP 和既有端点身份，防止排队期间设备变化。
- 系统音量百分比使用四舍五入，避免 49.999999 被截断显示为 49。
- PNG 导出在 WIC 读取位图前完成 GDI 批处理并解除 DC 选择，修复导出截图间歇缺字；实际屏幕和同步位图逐像素对照用于回归。
- 完全滚出区域的子控件使用空命中区域；高 DPI 下保持标题栏像素及点击区域。
- 遵循 Windows 减少动画设置，闲置时关闭动画计时器，隐藏窗口时停止动效。
