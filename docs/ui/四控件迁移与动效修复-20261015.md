新代码保留“请求目标”与“设备确认值”的区分。点击立即发送既有动作，动画不阻塞通信；失败恢复真实值，不把视觉状态当成耳机确认。

## 两种滑条与滚轮

默认仍为 Wake。主窗口“更多”按钮的右键菜单可切换 Wake / Elastic；普通点击“更多”仍打开既有功能窗口。样式通过 `desktop.ini` 的 `[UI] SliderStyle` 保存，修改前备份已有文件，不改其他键。

- 主窗口音量、环境声音：鼠标所在数值滑条消费滚轮；非滑条区域继续滚动窗口，分段和开关不响应数值滚轮。
- 已有工具窗口的每个 EQ 波段、Clear Bass、环境声音、系统音量、提示音量使用相同的滚轮路由与独立余量。
- 每个 120 delta 为一个设备支持的逻辑步长，保留带符号的小幅余量；向上加、向下减，按真实 min/max 夹紧；没有虚构 0.5 dB 或数字 ANC 档位。
- 禁用、断开、Ctrl+wheel 不写入。滚轮不抢键盘焦点；保留方向键、PageUp/Down、Home/End。
- 复用既有串行 debounce；跨波段的最新意图分别保留，避免一个波段替换另一个的未发值。执行前复核会话，音量继续复核 Windows 端点。
