# 按设备区分实体按钮、触摸控制和禁用态

2026-10-21，风险 L2。用户提供 WH-CH720N／1.0.8 官方 App 设置截图，并明确不能将该型号能力外推至 WH-1000XM5。沿用当前工作分支，修改前已 fetch Gitee；原有未提交内容保留。

## 修改

- `projects/cpp/native/include/sonyconnect/more_window.hpp`、`src/main_window.cpp`：增加只负责展示的设备控制描述。WH-CH720N 使用 `[NC/AMB] 按钮` 和“按钮切换的声音模式”，不再标注为左右耳触摸；触摸控制标记“此型号不支持”。按钮分配为固定说明，循环组合仍由已有有效读数和写入权限控制。
- WH-1000XM5 单独保留 `[NC/AMB]` 按钮和右侧触摸的语义，不继承 720N 的缺失功能。没有有效触摸分配接口/读数时显示“此版本尚未适配”，不能伪称硬件不支持，也没有凭空增加开关指令。WF-1000XM5 继续使用左右耳触摸分配。
- 720N 的名称为 DSEE；WF/WH-1000XM5 为 DSEE Extreme。其他未列明型号使用通用 DSEE 名称，不猜测增强版本。
- 更多设置、个性化/高级设置和诊断共用控件中的禁用态以 45% 图层透明度呈现；不可操作的选中循环项同时去除蓝色强调。相关说明文字淡化；720N 智能免摘和佩戴暂停注明不支持。原有输入守卫保留，禁用控件不派发操作；暂时 busy 不额外叠加透明度。
- `tests/more_window_tests.cpp`：增加 CH 按钮/缺失功能、WH 自身能力与右侧触摸、换回 WF 后恢复左右耳的场景，防止跨型号状态沿用。

这是展示差异，不是重新建立型号写入白名单。未修改协议字节、会话权限、codec 读取或多点策略。

## 编码信息核对

索尼 [WH-CH720N 官方规格](https://helpguide.sony.net/mdr/2966/v1/en/contents/TP1000783326.html) 列出 SBC、AAC，本身不支持 LDAC。因此不能将“开启多点后不能 LDAC”推导为“多点强制 AAC”，也不从操作系统名称推断实际编码。程序继续显示现有的设备实际 codec，随当前音源读取和刷新。

WH-1000XM5 的右侧触摸、智能免摘、佩戴检测及 DSEE Extreme 独立依据其 [官方 App 功能说明](https://helpguide.sony.net/mdr/wh1000xm5/v1/en/contents/TP1000534533.html) 和 [部件说明](https://helpguide.sony.net/mdr/wh1000xm5/v1/en/contents/TP1000534513.html)。本轮没有测试 WF/WH-1000XM5 的多点 LDAC 行为，也没有把用户提供的电脑 AAC、手机 LDAC 场景泛化成所有系统/固件的固定规则。
