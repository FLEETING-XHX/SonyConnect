2026-10-21，分支 `FLEETING/sc-32-connection-initialization`。风险等级 **L3**，用户已明确授权修复先前诊断的问题。修改前已 fetch Gitee；SC-34 和用户原有未提交修改保留。

## 修改

- `native/include/sonyconnect/protocol.hpp`、`native/src/protocol.cpp`：增加参数型 profile 判定。对于设备声明的 0xE1 连接模式，仅发送 E6 00 参数读取，不再发送该模式不适用的 E0 00 / E2 00。显式 capability/status 构造也拒绝这类 profile，防止以后重新引入。保留原有摘下暂停参数读取路径和其他 profile 查询顺序。
- `native/src/session.cpp`：参数型功能的二值候选来自协议定义；可用状态须等待合法参数回读，未知/哨兵值仍保持不可写。未改变 ACK/响应配对、超时隔离、重试、迟到响应或型号写入保护。
- `native/tests/protocol_tests.cpp`、`native/tests/session_tests.cpp`：增加参数型查询规划、初始化/刷新、未知值及其他 profile 路径保护用例。WH/LinkBuds/WF 名称的构造场景仅是离线测试，不代表对应型号实机验收。

以上路径均相对 `projects/cpp/`。
