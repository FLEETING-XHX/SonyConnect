- `projects/cpp/native/src/session.cpp`：取消通用功能的型号名白名单，改为当前控制连接已就绪、MDR V2、对应能力已报告、数据布局和当前回读有效、设备报告可用时开放。缺能力、未知值、非匹配布局、断连/旧会话和不可用状态的保护保留。

## 自检发现与修复

本轮打包发现旧许可复制自检的剪贴板恢复失败。早先做法保留的是 `OleGetClipboard` 实时数据对象引用，不能当作已经保存的完整内容；失败可能覆盖原剪贴板内容，已向用户说明。

`projects/cpp/native/src/app_host.cpp` 的自检现改为：先枚举并实体化所有格式及介质，失败则在复制前退出；随后复制许可，使用保存的数据对象恢复并 Flush。对暂时占用仅做有界重试。`projects/cpp/CMakeLists.txt` 增加 Windows 系统库 urlmon，用于复制保存介质。正常许可窗口的复制功能不变。

私有窗站方案因当前用户权限/名称限制未采用，相应尝试已撤回。最终保留的是无需额外管理员权限的数据快照方案，失败检查仍真实保留，最终运行复制与恢复均通过。实现依据：[IDataObject::GetData](https://learn.microsoft.com/en-us/windows/win32/api/objidl/nf-objidl-idataobject-getdata) 的介质所有权规则、[SHCreateStdEnumFmtEtc](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shcreatestdenumfmtetc) 的格式枚举接口及本机 Windows SDK 的 CopyStgMedium 声明。剪贴板内容不写入报告或日志。
