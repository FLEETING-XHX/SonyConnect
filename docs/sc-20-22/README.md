# SC-20～22 本地集成记录

本阶段实现自定义热键、GitHub／Gitee 更新渠道与 WF 已验证基线上的功能整合。正式 UI 与其他型号验收不属于本阶段；其他型号留在 SC-30～32。

## 实现范围

- 热键固定为一个识别键加一个自由键。识别键为左右 Ctrl、Alt、Shift，以及 Caps Lock、Tab；自由键支持 A～Z、F1～F12、Home、End、PgUp、PgDn 等。Backspace、Delete、PrintScreen 不作为识别键或自由键。
- 编辑器按下识别键即显示状态，区分左右键；提供冲突检查、失败保留草稿及原配置、原子保存和备份。
- 更新渠道提供 GitHub 更新与 Gitee 更新。根据用户确认，两仓库均公开，GitHub 默认匿名检查；私有授权逻辑继续由独立测试配置覆盖。
- Gitee 清单地址为 `https://gitee.com/fleetingxhx/SonyConnect/raw/main/update.json`。发布模板为 `config/gitee-update-manifest.example.json`，必须填写真实已发布版本后才能作为清单发布。
- 更新错误、超时及渠道切换不显示错误的“已是最新版”；检查更新不自动安装。

## 验收边界

2026-10-14 用户反馈“新版热键一切正常”，原始反馈记录见本目录 JSON。自动检查包括累计状态、协议、传输、协调用例，以及热键与更新渠道的离线用例、WPF 路由事件检查和发布程序验证。自动报告保存在忽略的 `artifacts/sc-20-22/run-*`。

离线用例不代替实机或线上发布验收。GitHub／Gitee 的真实新版本提示及 Gitee 清单、发行附件发布仍需实际发布后验证。正式 UI 不因此标记完成。未修改蓝牙协议或宣称新增型号支持。

本次按用户指令提交功能并合并本地 dev，然后从 dev 创建 C++ 分支；不推送、不发布、不执行 C++ 架构迁移。工作区其他文档整理与品牌图片保留在未提交状态。
